# GTA5ADM Desktop — обновления

Публичный канал Windows-приложения администрации GTA5ADM: локальный биндер, оверлей, репорты, статистика и инструменты.

Скачайте **`GTA5ADM.Desktop_<версия>_x64-setup.exe`** из [последнего релиза](https://github.com/blo0dy66/admin-releases/releases/latest). Нужны Windows 10/11 x64; установщик при необходимости докачает WebView2. Он устанавливается в профиль пользователя.

Со старого portable перейдите на установщик один раз. Установленные версии получают предложение обновления в **Настройки → О программе → Обновления**. Перед установкой остановите биндер и инструменты. Подпись Tauri проверяет обновление; сертификат Windows Authenticode в этом канале не используется.

При обновлении с 1.1.1 имя меняется на GTA5ADM Desktop, а профили, статистика, резервные копии и DPAPI-пароль сохраняются. Папка установки и data identifier сохраняют исторические имена для совместимости. Включённый автозапуск переносится на установленное приложение; отключённый остаётся отключённым. Автовход отправляет `/alogin13`.

Discord-вход, облачная синхронизация и встроенный дашборд находятся в разработке и в 1.1.2 ещё не включены. Для локального биндера аккаунт сайта не требуется.

## Содержимое релиза

- `*-setup.exe` — установщик.
- `*-setup.exe.sig` — подпись обновления.
- `latest.json` — манифест встроенного updater.
- `SHA256SUMS.txt` — контрольная сумма установщика.

**Исходники остаются закрытыми в `blo0dy66/admin`.** Здесь находятся инструкции, в release assets — дистрибутивы. GitHub автоматически показывает **Source code (zip/tar.gz)**: эти архивы содержат Git-дерево публичного репозитория с инструкциями, а не исходный код приложения. Для установки используйте `.exe`.

Данные приложения находятся в `%APPDATA%\app.novabinder`; личные данные и настройки в публичный канал не загружаются.
